# 📊 Atividade Prática: Estruturando Dados

## 🎯 Instruções

| Etapa | Descrição |
|-------|-----------|
| **1. Escolha o conjunto** | Cada grupo define um tema central |
| **2. Aplique a teoria** | Represente esse mesmo conjunto de três formas computacionais distintas |
| **3. Entregue o projeto** | Consolide as representações visuais e textuais em um repositório no GitHub |

---

## 🗂️ Estruturas Utilizadas

### Estrutura 1 — Lista
> Uma sequência simples, linear e ordenada de elementos.

### Estrutura 2 — Grafo
> Um mapeamento de conexões, destacando como elementos independentes se relacionam entre si.

### Estrutura 3 — Hierarquia
> Uma organização baseada em níveis de subordinação ou categorias de pertencimento.

---

## 📁 Conjunto de Dados Escolhido: Eventos do eSocial

O **eSocial** é um sistema do Governo Federal criado para unificar o envio de informações trabalhistas, previdenciárias e fiscais das empresas. Cada informação enviada ao eSocial possui um código específico chamado de **"evento"**. Esses eventos organizam os dados das empresas e permitem maior controle fiscal, trabalhista e previdenciário.

As estruturas desta atividade terão como tema os **principais eventos enviados ao eSocial** em uma rotina de departamento pessoal.
